登入你的聊天帳號

直接使用各平台提供的官方登入方式，不需要輸入 Bot Token、Webhook Secret 或手動設定使用者 ID。部分平台僅支援身分登入，無法讀寫私人聊天室。

T

Telegram

檢查設定

真正的個人帳號登入：手機號碼、驗證碼、雙重驗證。開發者須先配置一次官方 API ID／Hash。

S

Slack

檢查設定

使用 Slack 官方 OAuth 連結自己的工作區帳號。聊天室存取範圍依授權與組織政策而定。

D

Discord

檢查設定

以 Discord OAuth 驗證自己的帳號。登入不代表能由第三方直接讀取或代發個人私訊。

LINE

LINE

檢查設定

開啟 LINE 官方登入頁面（平台可能提供 QR 驗證）。只能取得基本身分，不能同步個人 LINE 聊天。

立即試用：本機示範帳號

不需要 Bot Token、OAuth 或真實帳號；可以查看三個模擬聊天室、發送訊息，並測試 @line:alice 的跨平台模擬轉送。不會傳送到任何真正的平台。
